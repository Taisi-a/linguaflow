# LinguaFlow

Веб-приложение для тех, кто занимается английским с репетитором. После урока ты записываешь заметку как в тетради, приложение находит в ней слова и правила, делает из них карточки и напоминает повторить их через нужный интервал.

Я сделала его для себя: после каждого занятия у меня оставалась тетрадь с новыми словами, и через неделю нужное в ней уже было не найти. Дизайн приложения я сначала спроектировала в Figma ([кейс в портфолио](https://taisi-a.github.io)), а потом сверстала по нему интерфейс.

## Как это работает

1. **Заметка.** Одно большое поле вместо формы на каждое слово: дата урока, тема, текст в свободной форме.
2. **Слова из заметки.** LLM (Gemini) находит английские слова, выражения и грамматические правила, добавляет перевод, транскрипцию, пример и пометку репетитора. Ответ модели проверяется Pydantic-схемой; при невалидном ответе запрос повторяется. Слова, которые уже есть в словаре, сразу помечены как известные.
3. **Повторение.** Карточка с контекстом («Из заметки «Phrasal verbs», 21 окт»), озвучкой и четырьмя оценками. Под каждой кнопкой видно, когда слово вернётся.
4. **Итог и серия.** Сколько слов вспомнилось сразу, сколько вернётся сегодня и завтра, сколько дней подряд без пропусков.

Если ключа Gemini нет или сеть недоступна, работает запасной разбор строк вида `come up with — придумать`, а интерфейс честно говорит, что ИИ сейчас недоступен.

## Интервальное повторение

Алгоритм — SM-2 в варианте Anki (`app/services/srs.py`). Новая карточка проходит короткие шаги: «Не помню» — через 1 минуту, «Сложно» — через 10 минут. После «Помню» она переходит в повторение по дням (1 день), после «Легко» — сразу на 4 дня. Дальше интервал умножается на коэффициент лёгкости (ease, по умолчанию 2.5), который растёт от «Легко» и падает от «Сложно» и «Не помню» (не ниже 1.3). Забытая карточка возвращается в короткие шаги, а интервал начинается заново.

Модуль не зависит от БД и веб-фреймворка: на вход состояние и оценка, на выход новое состояние. Поэтому вся логика покрыта обычными юнит-тестами.

## Стек

Python 3.10+, FastAPI, SQLAlchemy 2.0, Alembic, PostgreSQL (SQLite для локального запуска), Pydantic, JWT (httpOnly-cookie) + bcrypt, Gemini API, Jinja2, pytest, ruff, Docker, GitHub Actions.

Интерфейс — серверные шаблоны без фронтенд-фреймворка и немного ванильного JS (переворот карточки, горячие клавиши, озвучка через Web Speech API). Без JS всё тоже работает.

## Структура

```
app/
  main.py            # сборка приложения, роутеры, обработка неавторизованных запросов
  config.py          # настройки из .env (pydantic-settings)
  models.py          # User, Note, Card, ReviewLog
  security.py        # bcrypt и JWT
  routers/           # auth, notes, words, study (сегодня, повторение, профиль)
  services/
    srs.py           # SM-2: чистые функции без БД
    extraction.py    # Gemini, проверка ответа, запасной разбор строк
    study.py         # очередь повторения, итог сессии, серия, статистика
  templates/, static/
alembic/             # миграции
scripts/eval_extraction.py  # оценка качества извлечения слов
tests/
```

## Запуск

### Локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env          # впиши SECRET_KEY и GEMINI_API_KEY
alembic upgrade head
uvicorn app.main:app --reload
```

Открой http://localhost:8000 и зарегистрируйся. Ключ Gemini бесплатно выдаётся в [Google AI Studio](https://aistudio.google.com/apikey).

### В Docker (с PostgreSQL)

```bash
cp .env.example .env
docker compose up --build
```

Миграции применяются автоматически при старте контейнера.

## Тесты

```bash
pytest -q
ruff check .
```

Тесты покрывают алгоритм повторения, разбор ответов LLM (включая повтор запроса и запасной режим), авторизацию, доступ к чужим данным и полный сценарий «заметка → карточки → повторение → итог». LLM в тестах подменяется заглушкой через `dependency_overrides`. В CI те же тесты плюс прогон миграций на PostgreSQL.

## Оценка качества извлечения

Насколько хорошо модель находит слова, проверяется на размеченных заметках:

```bash
cp eval/dataset.example.json eval/dataset.json   # добавь свои заметки и ожидаемые слова
python -m scripts.eval_extraction eval/dataset.json
```

Скрипт считает precision, recall и F1 для LLM и для запасного разбора строк и сохраняет разбор промахов по каждой заметке в `eval/results/latest.json`.
