# 🎯 LinguaFlow - AI-Powered English Learning Platform

**LinguaFlow** — это полнофункциональная веб-платформа для изучения английского языка с интеграцией искусственного интеллекта. Проект сочетает умный словарь, систему отслеживания прогресса и AI-помощника для персонализированного обучения.


## ✨ Особенности

### 🎓 Обучение
- **Умный словарь** с системой интервального повторения
- **AI-генерация** упражнений по слабым местам
- **Адаптивные тесты** с проверкой через нейросети
- **Заметки к урокам** с анализом прогресса

### 👤 Личный кабинет
- Полный контроль над процессом обучения
- Визуализация прогресса по навыкам
- Цели и достижения
- История занятий

### 🤖 AI Интеграция
- Google Gemini API для генерации контента
- Анализ ответов на стиль и уместность
- Персонализированные рекомендации
- Проверка произношения (в разработке)
